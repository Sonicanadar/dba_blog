Daily DBA checklist
  1. Confirm the database and listener/service are up.
  2. Check last night's backup finished and passed verification.
  3. Review free space on data files, logs and disks.
  4. Look for long-running, blocked or failed sessions and jobs.
  5. Scan the error log and alerts for new warnings.
  6. Check replication or standby lag.

About DBAMyWorld

DBAMyWorld is a practical DBA reference for Oracle, PostgreSQL, MySQL and SQL Server.

It brings together step-by-step administration guides, troubleshooting notes, SQL and command examples, architecture references, and interview questions in one searchable place.

What you can use it for

  • Daily database administration and health checks
  • Performance investigation and troubleshooting
  • Backup, recovery and high-availability preparation
  • Security and configuration reference
  • DBA interview preparation

Always test commands in a suitable non-production environment and verify them against the documentation for your database version before making production changes.
