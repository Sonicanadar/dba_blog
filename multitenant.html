Hot Cloning a Local Pluggable Database (PDB)

ADMIN TARGET: DDL GENERATION

Clones an active pluggable database directly from a running source PDB container without interrupting live read-write transactions or application workflows.

Container Execution Script:

-- Connect to CDB$ROOT as administrative user\nCREATE PLUGGABLE DATABASE hr_pdb_test FROM hr_pdb_prod;\nALTER PLUGGABLE DATABASE hr_pdb_test OPEN READ WRITE;
