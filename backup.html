Full Database Compression Backup Block

TARGET COMMAND: RMAN COMPRESSED BACKUP

Executes a binary compression pool backup of the root target environment including datafiles, initialization files, and dynamic archive log segments, then completely clears down expired transaction traces from storage tracks.

RMAN Terminal Command String:

RUN {\n  ALLOCATE CHANNEL c1 DEVICE TYPE DISK;\n  BACKUP AS COMPRESSED BACKUPSET DATABASE PLUS ARCHIVELOG DELETE INPUT;\n  RELEASE CHANNEL c1;\n}
