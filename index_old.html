Daily DBA checklist
  1. Confirm the database and listener/service are up.
  2. Check last night's backup finished and passed verification.
  3. Review free space on data files, logs and disks.
  4. Look for long-running, blocked or failed sessions and jobs.
  5. Scan the error log and alerts for new warnings.
  6. Check replication or standby lag.

Daily DBA Challenge

Production database suddenly becomes slow

CPU is high and users report slow response. What would you check first?

Suggested approach

Start with current workload: check CPU, active sessions, blocking/locks, wait events and top SQL. Then correlate the database symptoms with the host and application before making changes.

About the website

DBAMyWorld

A focused DBA reference for Oracle, PostgreSQL, MySQL and SQL Server. Find practical administration guides, troubleshooting references, SQL examples, architecture material and interview questions in one searchable place.

What DBAMyWorld is for

The site is organized around practical database administration work: understanding a topic, reviewing the relevant steps, and checking the example commands before using them in your own environment.

What you can find

  • Installation, configuration, patching and upgrade references
  • Backup, recovery, replication and high-availability topics
  • Performance, locking, monitoring and troubleshooting guides
  • Advanced DBA topics and interview questions
